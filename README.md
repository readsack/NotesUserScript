# Notes User Script
This is a userscript for violentmonkey which adds a notes widget to the bottom-left corner of your screen, which allows you to store any interesting piece of information you might come across while surfing.

## Features
- Works with almost all webpages
- Allows you to add little notes, along with the selected text
- Allows you to view all saved notes in one place and manage them.

## Getting Started
- Download the notes.user.js script
- Drop it into [ViolentMonkey](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)
- Reload the page and Viola!
